*VRAM note. Peak PyTorch VRAM is the model process's own maximum CUDA allocation over load and synthesis. GPU used peak is whole-device usage and can include other MIG tenants, so it is not attributable to the model.
Method. Both models receive the same female Marathi reference clip and transcript, the same 13 target translations, one seed (1234) and the same sequential GPU allocation. OmniVoice uses its declared language code for each target (as, bn, gu, hi, mr, ory, pa, sa, kn, ml, ta, te, en); IndicF5 infers language from the target text. CER/WER use faster-whisper large-v3 (per-language where supported) where that language is supported; CSIM is ECAPA cosine similarity to the reference voice; DNSMOS-OVRL is predicted MOS. RTF = synthesis seconds per second of audio.
Coverage caveats. IndicF5 declares support for 11 Indian languages, not Sanskrit or English. Its Sanskrit and English samples are extrapolations and should not be read as supported capability. Whisper large-v3 has no Odia language code, so Odia CER/WER are unavailable. Whisper is also weak on some Indic languages and on Sanskrit; do not treat ASR numbers as absolute pronunciation scores. The result is one sentence per language, not a full linguistic coverage evaluation. Listen to the samples, especially before using a language outside a model's declared support.
