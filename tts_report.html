Method. Both models get the same Marathi reference clip and transcript (zero-shot cloning), the same four target texts and the same GPU slice. WER/CER come from faster-whisper large-v3 (mr) against the target text; CSIM is the ECAPA cosine similarity to the reference voice. Predicted MOS uses UTMOS when available, otherwise DNSMOS (OVRL). RTF = synthesis seconds per second of generated audio (lower is better). Whisper large-v3 is not a strong Marathi ASR model, so WER/CER are ASR-dependent and should be read together with CER, CSIM and listening. The numbers prompt is especially affected because ASR may render Devanagari digits as words. Manual MOS is left blank by design.
